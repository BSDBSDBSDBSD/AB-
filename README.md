# Duplicate Song Finder (Android, offline)

אפליקציית אנדרואיד קטנה שסורקת את כל השירים במכשיר (דרך MediaStore), מזהה כפילויות
לפי דמיון בשם הקובץ (fuzzy matching, לא צריך שם זהה לגמרי) בשילוב עם טווח סטייה
באורך השיר, ומאפשרת למחוק ישירות מהמכשיר. הכול רץ מקומית, בלי רשת ובלי שרת.

## איך לבנות ולהריץ

1. התקן [Android Studio](https://developer.android.com/studio) (גרסה עדכנית, Hedgehog ומעלה).
2. `File → Open` ובחר את התיקייה `DuplicateSongFinder` (התיקייה הראשית, לא `app`).
3. תן ל-Gradle לסנכרן (בפעם הראשונה זה מוריד תלויות – כאן כבר צריך אינטרנט).
4. חבר מכשיר אנדרואיד (עם ניפוי שגיאות USB מופעל) או הרץ אמולטור.
5. לחץ Run ▶. האפליקציה תתקין ותופעל עם הסמל "Duplicate Song Finder".

## שימוש

1. באפליקציה, אשר גישה לקבצי מדיה כשמתבקש.
2. כוונן את שני הסליידרים: אחוז דמיון בשם השיר, וטווח סטייה מותר באורך (בשניות).
3. לחץ "סרוק את המכשיר". יופיעו קבוצות של שירים שזוהו ככפולים.
4. אפשר למחוק כל שיר ישירות מהרשימה (מחיקה אמיתית מהמכשיר). באנדרואיד 10 ומעלה
   תופיע חלונית אישור מערכת לפני המחיקה בפועל.

## הערות טכניות

- `minSdk = 26` (אנדרואיד 8+), נבדק מול `targetSdk = 34`.
- ההרשאה המבוקשת היא `READ_MEDIA_AUDIO` (אנדרואיד 13+) או `READ_EXTERNAL_STORAGE`
  (גרסאות ישנות יותר).
- ההתאמה בין שמות מתעלמת מניקוד, מסוגריים, ומילים כמו official/remix/feat/live וכו',
  ומשתמשת במרחק לוינשטיין כדי לחשב אחוז דמיון.
- אין תלות ברשת בזמן ריצה — כל הלוגיקה מקומית על המכשיר.
- קוד כתוב ב-Kotlin + Jetpack Compose, קובץ יחיד עיקרי: `MainActivity.kt`.

## התאמות אפשריות (לא כלולות)

- שמירת דו"ח כפילויות כקובץ טקסט/CSV.
- מיון קבוצות לפי איכות/ביטרייט כדי להציע איזה עותק לשמור.
- סינון לפי תיקייה ספציפית בלבד.
